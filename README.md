## Verification

All commits in this repository are SSH-signed and timestamped via [OpenTimestamps](https://opentimestamps.org/).

```bash
# Verify commit signatures
git log --show-signature

# Verify blockchain timestamp
pip install opentimestamps-client
ots verify proofs/<commit-sha>.ots
```
